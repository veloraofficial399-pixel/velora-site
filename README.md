## 📱 Features & Highlights

1. **Realistic Smartphone Interactive Mockup in Hero**:
   - Interactive live preview with couple names, real-time countdown clock, Google Maps directions, and interactive RSVP button.
2. **Interactive Live Preview Modal**:
   - Device switcher: **Mobile (iPhone 16 Pro)**, **Tablet (iPad)**, **Desktop (MacBook)**.
   - Live embedded Vercel website iframe with fallback and direct new tab launcher.
   - Sample details tab with wedding story, venue schedule, and interactive guest RSVP test.
3. **Digital Invitations Gallery**:
   - Wedding Invitations, Engagement, Save the Date, Reception, Nikah, Birthday.
   - Filter by category with animation format badges (Vertical Video, Interactive PDF, E-Card).
4. **Transparent Packages & Pricing**:
   - Starter (₹499), Classic (₹799), Royal (₹999) + expandable Haute & Bespoke collections.
   - All editable via the owner CMS.
5. **How It Works connected 4-step timeline**:
   - 01 Choose Design → 02 Share Details → 03 Personalise Website → 04 Share Invitation.
6. **Functional Contact Form & WhatsApp Integration**:
   - Submits leads to internal state / CSV export, provides immediate confirmation reference ID, and includes one-click continuity directly to WhatsApp with pre-filled enquiry text.
7. **Discreet Owner Content Management System (CMS)**:
   - Click "Owner CMS" in footer.
   - Enter passcode: `velora2026`.
   - Manage WhatsApp number, Instagram handle, add/delete templates, adjust prices, and export customer leads to CSV.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS with custom luxury tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel ready (`vercel.json`) & GitHub

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

---

## 🚢 Deploying to Vercel

1. Push your repository to GitHub:
   ```bash
   git remote add origin https://github.com/your-username/velora.in.git
   git branch -M main
   git push -u origin main
   ```
2. Go to [Vercel](https://vercel.com) and click **Add New Project**.
3. Select your `velora.in` repository.
4. Framework preset will automatically detect **Vite**.
5. Click **Deploy**!

## 🎨 Logo Customization Note

To replace the logo with the original Velora graphic file, simply place your transparent PNG or SVG logo into:
```
public/logo.png
```
The website will automatically detect it and render it across all navigation bars, hero headers, loaders, and footers!
